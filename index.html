nodespot GitHub

A native radio node with a web control panel

nodespot lets you connect, monitor and manage favorites with live status from any browser, and it can set up digital modes for you. It runs on Debian 12 (bookworm), Debian 13 (trixie) and Raspberry Pi OS (arm64 and amd64; 64-bit only).

  • Latest release 1.0.0
  • Latest beta 1.0.0 (same as stable)

Docs, screenshots and bug reports are on GitHub.

Quick install

Run this on the node (over SSH or in a terminal):

curl -fsSL https://w1jar.github.io/nodespot/install.sh | sudo sh

Run this on the node (over SSH or in a terminal). It works on plain Debian 12/13 or Raspberry Pi OS Lite 64-bit. nodespot runs its own node: it does not need AllStarLink 3 or Asterisk.

On a freshly flashed card, wait for its first-boot setup to finish before you install. The installer checks this.

At the end the installer prints a one-time setup link. Open it to create the administrator or to restore a backup from an existing node. sudo nodespot admin setup-code shows the code again.

Install options

Pick what you need and copy the command. Everything is optional.

Port 80 and other web services
Web port

1024-65535, or 80; 8080 is the default. Avoid 9090 (Cockpit). Port 80 is set for you by the option above.

Channel

Your command

curl -fsSL https://w1jar.github.io/nodespot/install.sh | sudo sh

Add these before sh, after sudo, separated by spaces. All are optional:

NODESPOT_PORT=8181
Web port, 1024-65535, or 80. The default is 8080. Avoid 9090 (Cockpit).
NODESPOT_TAKEOVER=1
Run nodespot on port 80 and turn off web services an earlier ASL install left (yes and true work too). See below.
NODESPOT_CHANNEL=beta
Use the beta channel (new builds before they are promoted to stable). The default is stable.

Example with several options:

curl -fsSL https://w1jar.github.io/nodespot/install.sh | sudo NODESPOT_PORT=8181 NODESPOT_CHANNEL=beta sh

nodespot on port 80, no other web UI

A card that ran ASL3 before may still run Apache, Allmon3 and the ASL web UI. To make nodespot the only web UI, on port 80:

curl -fsSL https://w1jar.github.io/nodespot/install.sh | sudo NODESPOT_TAKEOVER=1 sh

The installer stops and disables Allmon3, the web server of the ASL web UIs (Apache, lighttpd or nginx), asl-web-ui and Supermon, but only those that exist and are on, and lists each one. The node keeps running. Nothing is uninstalled. Then nodespot moves to port 80 and the panel is at http://your-node/. If something else still holds port 80, the installer names it and leaves nodespot on its old port.

To undo it (nodespot goes back to its old port and the units it turned off are enabled and started again):

curl -fsSL https://w1jar.github.io/nodespot/install.sh | sudo NODESPOT_TAKEOVER=undo sh

Changing things later

Web port

The web interface listens on port 8080 by default. To change it, run the installer again with NODESPOT_PORT (1024-65535, or 80), or edit listen in /etc/nodespot/nodespot.conf (for example listen = :8181) and run sudo systemctl restart nodespot. The installer warns if another program already uses the port.

If firewalld is running, the installer and the package open the configured port for you. With another firewall (ufw, nftables, a router) open the TCP port yourself. If you edit listen by hand while firewalld is running, open the new port too.

Update

Use Settings → Updates in the web UI, or:

sudo apt update && sudo apt upgrade

Uninstall

sudo apt remove nodespot   # keeps users and favorites
sudo apt purge nodespot    # also deletes them

apt purge also deletes the node config (which holds network passwords).

Manual apt setup

Prefer not to pipe a script? Add the signed repository yourself:

sudo curl -fsSL -o /usr/share/keyrings/nodespot-archive-keyring.gpg https://w1jar.github.io/nodespot/nodespot-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/nodespot-archive-keyring.gpg] https://w1jar.github.io/nodespot stable main" | sudo tee /etc/apt/sources.list.d/nodespot.list
sudo apt update && sudo apt install nodespot

Signing key fingerprint: CA81DA7CEA379617CD0B8DEF32F7D07C73433182 (armored key)

Beta channel

Every new version goes to the beta suite as soon as it is built. It becomes a release (suite stable) when it is promoted after testing: the same package, not a rebuild. The beta suite also carries every release, so beta users are never behind. Betas may be less stable.

To use it, put beta instead of stable in the line above:

echo "deb [signed-by=/usr/share/keyrings/nodespot-archive-keyring.gpg] https://w1jar.github.io/nodespot beta main" | sudo tee /etc/apt/sources.list.d/nodespot.list

Or install with NODESPOT_CHANNEL=beta (see the options above), or switch in Settings → Updates in the web UI. It is the same setting: it changes the suite in /etc/apt/sources.list.d/nodespot.list. Going back to stable does not downgrade: the node stays on the installed version until a release newer than it is promoted.
